## 一、模型总体框架

### 1.1 框架思路

使用 2018–2026 年国家队比赛构建动态 Dixon–Coles 模型，基于 FIFA 积分和主客场优势，加入对手校正 xG、阵容深度、休息时间和场地变量，从本届已结束的赛事开始动态更新，基于 2026 年的 12 个小组和 32 队淘汰赛规则进行 20 万次模拟。

### 1.2 数据流水线

1. 历史比赛 → 球队攻防先验经验
2. 已完成的 2026 比赛 → 对手调整、xG 更新
3. 确认首发、换人和场地 → 更新双方预期进球
4. Dixon–Coles + GBM + BTD → 概率矩阵
5. 按官方规则模拟剩余比赛 → 晋级和夺冠概率

### 1.3 三模型加权融合

$$P_{\text{final}}(x, y) = w_1 P_{DC}(x, y) + w_2 P_{GBM}(x, y) + w_3 P_{BTD}(x, y)$$

其中：
- $P_{DC}$: 动态 Dixon–Coles 比赛概率
- $P_{GBM}$: 梯度提升模型（Gradient Boosting Machine）非线性修正
- $P_{BTD}$: Bradley–Terry–Davidson 或 Elo 胜负模型
- 约束：$w_1 + w_2 + w_3 = 1,\; w_k \geq 0$

### 1.4 与 Opta 融合

$$P_{\text{最终}} = 0.75 \, P_{\text{本模型}} + 0.25 \, P_{\text{Opta}}$$

（另有画面显示比例为 70:30，可能针对不同赛事阶段有不同配置）

### 1.5 主要评价指标

- 概率矩阵负对数似然（Negative Log-Likelihood）
- 胜/平/负 Log Loss
- Brier Score & RPS（Ranked Probability Score）
- 概率校准曲线（Calibration Curve）

### 1.6 概率校准公式

$$P_f(x, y) = P_{DC}(x, y) \frac{P_{\text{final}}(z)}{P_{DC}(z)}$$

## 二、核心公式体系

### 2.1 主模型：动态层级 Dixon–Coles

预测双方的预期进球：

$$\log(\lambda_A) = \mu + Attack_{A,t} - Defence_{B,t} + \beta^\top X_{A,B,t}$$

$$\log(\lambda_B) = \mu + Attack_{B,t} - Defence_{A,t} + \beta^\top X_{B,A,t}$$

协变量 $X$ 包含：$\Delta Elo,\; \Delta xGForm,\; \Delta Lineup,\; Host,\; Rest,\; Travel,\; Venue,\; Incentive$

Dixon–Coles 联合概率：

$$P(A=x, B=y) = \tau(x, y; \rho) \cdot Pois(x; \lambda_A) \cdot Pois(y; \lambda_B)$$

$\tau$ 是 Dixon–Coles 修正项，处理 0:0、1:0、0:1、1:1 等低比分出现频率与独立泊松假设不一致的问题。

### 2.2 Elo 基础期望进球率

$$\lambda_{i,0} = \mu \exp\left(\frac{R_i - R_j + H_i - H_j}{s}\right)$$

参数设定（出现多个版本）：

| 参数 | 版本A | 版本B | 版本C |
|------|-------|-------|-------|
| $\mu$（基础进球率） | 1.25 | 1.25 | 1.25 |
| $s$（Elo 缩放因子） | 750 | 800 | 600 |

简化形式：$\lambda_{A,0} = 1.25 \exp\left(\frac{R_A - R_B}{600}\right)$，$\lambda_{B,0} = 1.25$

### 2.3 结构性进球均值

$$\lambda_L^{(0)} = \frac{A_L + D_R}{2} \exp\left(\frac{E_L - E_R}{1200}\right)$$

$$\lambda_R^{(0)} = \frac{A_R + D_L}{2} \exp\left(-\frac{E_L - E_R}{1200}\right)$$

Elo 包含了首轮结果，首轮 xG 只给予 15% 的额外权重，防止重复计算：

$$\lambda_i = \lambda_i^{(0)} \exp[0.075(r_i^{att} + r_j^{def})]$$

### 2.4 攻击力与防守力系数（clip 归一化）

**版本 A:**

$$A_i = \text{clip}\left(\frac{8\mu + XGF_i}{10\mu},\; 0.88,\; 1.12\right)$$

$$D_i = \text{clip}\left(\frac{8\mu + XGA_i}{10\mu},\; 0.88,\; 1.12\right)$$

**版本 B:**

$$A_i = \text{clip}\left[1 + 0.20\left(\frac{\overline{GF_i}}{1.35} - 1\right),\; 0.80,\; 1.25\right]$$

$$D_i = \text{clip}\left[1 + 0.20\left(\frac{\overline{GA_i}}{1.35} - 1\right),\; 0.80,\; 1.35\right]$$

其中 $\overline{GF_i}$ 为场均进球数，$\overline{GA_i}$ 为场均失球数，$1.35$ 为基准均值参考值。

### 2.5 最终期望进球率

**乘法形式:**

$$\lambda_i = \lambda_{i,0} \sqrt{A_i \, D_j \, S_i}$$

**连乘因子形式:**

$$\lambda_i = \lambda_{0,i} \times F_{\text{状态}} \times F_{\text{年龄}} \times F_{\text{阵容}} \times F_{\text{裁判}} \times F_{\text{赛况}}$$

### 2.6 年龄修正因子

$$F_{\text{年龄}} = \exp\left[0.012(27 - \overline{Age}) + 0.004(U23 - 4) - 0.003(N_{30+} - 6)\right]$$

约束：$0.96 \leq F_{\text{年龄}} \leq 1.04$

- $\overline{Age}$：球队平均年龄，基准值 27 岁
- $U23$：23 岁以下球员数量，基准值 4 人
- $N_{30+}$：30 岁以上球员数量，基准值 6 人

### 2.7 情景修正系数

$$S_i = S_j = 1 + \sqrt{\text{紧迫}_i \cdot \text{紧迫}_j}$$

### 2.8 时间衰减权重

$$w = \exp\left(-\frac{\ln 2}{730} \times \text{距今天数}\right)$$

半衰期为 730 天（约 2 年），即 2 年前的比赛数据权重衰减至 50%。

完整历史比赛权重：

$$w_k = \exp\left(-\ln 2 \times \frac{\text{距今天数}}{h}\right) \times \text{赛事重要性}$$

从一年半衰期开始，再由滚动验证选择最佳值。世界杯、洲际杯和预选赛通常比友谊赛权重高。

### 2.9 GBM 修正

$$\log \lambda_A^{\text{final}} = \log \lambda_A^{\text{Poisson}} + f_{GBM}(X)$$

在对数空间中将泊松模型的基础参数与梯度提升机（GBM）的修正项叠加，得到最终的进攻强度参数。

### 2.10 进攻/防守时序更新

$$Attack_{i,t} = Attack_{i,t-1} + \varepsilon_t$$

### 2.11 各因子定义

| 因子 | 定义 |
|------|------|
| $\lambda_0$ / $F_0$ | 长期实力、预选赛表现、攻防评级和对手强度给出的基础期望进球 |
| $F_{\text{状态}}$ | 首轮 xG、射门质量、门将表现和比赛过程；首轮只占约 20% 权重，避免把 5 球、7 球直接外推 |
| $F_{\text{年龄}}$ | 阵容平均年龄、U23 球员数量、30 岁以上球员数量，并对边锋和边后卫年龄给予更高权重 |
| $F_{\text{阵容}}$ | 伤停、预计首发和可用替补 |
| $F_{\text{裁判}}$ | 点球、红牌和比赛失控风险 |
| $F_{\text{赛况}}$ | 积分需求、平局接受程度、比赛节奏和天气 |

## 三、泊松概率计算

### 3.1 双独立泊松联合概率分布

$$P(G_A = x,\; G_B = y) = e^{-(\lambda_A + \lambda_B)} \frac{\lambda_A^x}{x!} \frac{\lambda_B^y}{y!}$$

假设主客队进球数 $G_A$ 和 $G_B$ 相互独立，均服从泊松分布。

### 3.2 Dixon-Coles 联合概率（含 tau 修正）

$$P(X = x,\, Y = y) = \tau_\rho(x,\, y) \; \frac{e^{-\lambda_i} \lambda_i^x}{x!} \; \frac{e^{-\lambda_j} \lambda_j^y}{y!}$$

其中 $\rho = -0.05$。

### 3.3 tau 修正项定义

| 比分 $(x,y)$ | $\tau$ 值 |
|:---:|:---:|
| (0,0) | $1 - \lambda_i \lambda_j \rho$ |
| (1,0) | $1 + \lambda_j \rho$ |
| (0,1) | $1 + \lambda_i \rho$ |
| (1,1) | $1 - \rho$ |

### 3.4 胜平负概率计算

$$P(\text{A胜}) = \sum_{x > y} P(x, y)$$

$$P(\text{平局}) = \sum_{x = y} P(x, y)$$

$$P(\text{B胜}) = \sum_{x < y} P(x, y)$$

### 3.5 大比分概率

**总进球 ≥ 4:**

$$P(\text{总进球} \geq 4) = 1 - \sum_{x+y \leq 3} P(x, y)$$

**单队进球 ≥ 3:**

$$P(\text{A} \geq 3) = 1 - \sum_{x=0}^{2} \sum_{y=0}^{\infty} P(x, y)$$

**净胜 3+ 球:**

$$P(|x - y| \geq 3) = \sum_{|x-y| \geq 3} P(x, y)$$

### 3.6 数值计算示例

**P(0,1) 示例:**

$$P(0, 1) = e^{-2.35} \times 1.70 = 0.162$$

其中 $e^{-2.35}$ 来自 $e^{-(\lambda_A + \lambda_B)}$ 部分，$1.70$ 为 $\frac{\lambda_A^0}{0!} \times \frac{\lambda_B^1}{1!} = \lambda_B$。

**P(2,0) 示例:**

$$P(2, 0) = e^{-3.35} \times \frac{2.90^2}{2!} = 0.148$$

**P(2,0) 葡萄牙 vs 乌兹别克斯坦:**

$$P(2, 0) = e^{-1.932} \frac{1.932^2}{2!} \times e^{-0.720} \approx 13.2\%$$

其中：$\lambda_{\text{葡}} = 2.092 \times 0.923 \times 1.000 = 1.932$，$\lambda_{\text{乌}} = 0.747 \times 1.024 \times 0.942 = 0.720$
