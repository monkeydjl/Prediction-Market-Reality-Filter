后端有、前端缺的功能
1. M3 Edge 轨迹可视化（高价值）
后端 GET /events/{id}/history 已返回完整的 EdgeTrajectory（observations, peakedge, netedgechange, classification, freshnessband），但前端只在决策卡片上显示一个文本 freshness 标签。缺少一个 edge-over-time 折线图，能看到 AI vs 市场的 divergence 如何演变、何时达到峰值、当前处于 fresh/decaying/stale。

2. M2 Disagreement Diagnosis 深入展示（高价值）
后端 diagnose() 返回 trust、adjustededge、liquidityfactor、qualified、segmentn、segmentskill。前端决策卡片展示了其中一部分，但缺少：

各分类 skill 得分的柱状图（一眼看出哪些分类可信）
trust 分解：校准信任度的来源
样本量趋势（segments 何时能 qualified）
3. Fresh Edge 独立页面（中价值）
GET /api/events/edges/fresh 接口已存在，但只在决策页面以新鲜度标记存在。缺少一个专门的边缘监测页，按 fresh/decaying/stale/closed 分组，带时间线可视化。

4. 系统运维面板（中价值）
/api/events/loop/status 返回 scheduler 状态、run 历史、错误记录，但前端 SystemStatus 组件很简陋——没有历史时间线、失败详情、运行时长图表。

5. 批量结算工作流（中价值）
"立即结算"按钮一键执行，缺少先预览匹配结果、再确认提交的审核流程。

6. 待审链接改进（低价值）
当前只是列表 + 验证按钮，缺少对比查看相似度、并排比较市场契约的界面。

前端架构可优化点
数据层
无 React Query/SWR：手动 useEffect + fetch，15 秒内存缓存，无后台刷新
无 WebSocket/SSE：必须手动刷新
无分页：全部用 "load more"，大数据量不便
Type 手写：前后端类型不同步，无代码生成
交互体验
无自动刷新：dashboard 不会自动更新最新概率变化
搜索/筛选不持久：EventTable 的搜索不会保留在 URL 中
Chart 无交互：概率图不支持缩放/选区
无骨架屏：全部是文字"加载中…"
Loading 状态不精细：不分 section 颗粒度
